Terminals 列表 · 第二稿：两层、组头、一个搜索

配 docs/terminal-v0.md §1「列表的主次与找会话」。第一稿的三种改法按查到的规范收成一套：侧栏只两层（文件夹是组头，组里是终端和会话；子文件夹自己成一组，前面淡色写上一组的名字），组头比行大一号、主色、上面空一段，滚动时停在顶上；组里先是开着的终端，再是 // History 分隔线下的历史会话；收起、展开都记住；会话能置顶、改名；只有一个搜索（⌘F）：没打字时是最近的，打字分组出结果，@ 选文件夹缩小范围；另有按时间看。下面的窗口能点：组头（收起）、// History、Show All、行（选中，右边打开）、右键（组头、终端、会话）、搜索框（能打字，↑ ↓ ↩ esc，打 @）、过滤行的 agent、◷、Active。文件夹、终端、会话都是编的。

4 · 和现在比，改了什么
  1. 两层。每个有自己终端或会话的文件夹都是一组。子文件夹不再缩进到父文件夹里面：它自己成一组，排在父文件夹后面（按路径排，所以总是挨着），组头前面淡色写上一组的名字（lumen/ packages/api）。只用来归类的文件夹（现在的 Projects/、packages/）不再占一行，名字进了前缀。
  2. 组头像组头。比行大一号（经典 14 点半粗，现在是 12 点次要色）、主色、上面空一段；文件夹图标用强调色。滚动时停在顶上，下一组把它推走，停住时底下一条细线。右边是开着的终端数（等你时琥珀色）和会话数，git 状态在名字后面、先被挤掉。
  3. 组里的顺序：开着的终端（按打开先后，子代理在它下面）→ // History · N → 历史会话。分隔线只在组里有终端时出现，点它只收起历史；没有终端的组直接是历史。
  4. 历史会话淡一档：经典 12.5 点次要色、行矮一点；置顶的排在最前、带图钉，然后按开始时间新的在上；露 3 条，Show All 9 展开、Show Fewer 收回，都记住。
  5. 右键会话：Resume Resume As · Rename Pin to Top · Search in “lumen” Show in Files · Delete。改名只改列表里显示的名字，悬停能看到第一句话。组头右键多一个 Search in “lumen” 和 Collapse Others。
  6. 一个搜索：⌘F。没打字时是 Recent Searches（可 Clear）和 Recently Opened；打字就出结果，分四组、每条两行，↑ ↓ 选、↩ 打开、⌘↩ 在旁边一块打开、esc 清空再退出，退出后列表展开到打开的那一行。@ 选文件夹（含它下面的），变成框里的一个标签，⌫ 删掉；agent 仍在过滤行选，两样能一起用。
  7. 按时间看（过滤行的 ◷）：开着的终端在最上面，历史按开始时间分 Today Yesterday Previous 7 Days Previous 30 Days、再按月、按年，每条第二行写文件夹；组名停在顶上。
  8. 手机同一套（第 2 节）。
5 · 等你定
  1. 两层，还是留着嵌套？这一稿照 HIG 改成两层，等于收回 10 月 3 日的“按真实层级嵌套”（那时的问题是两个 Worktop、靶场 独立在外——两层下它们按路径挨着，前缀写清是谁的）。另一条路：留着嵌套，只改组头、顺序、记住和搜索。
  2. 按时间看要不要。不要的话过滤行少一个 ◷，找“昨天那个”靠 ⌘F 的 Recently Opened。
  3. 改名记在哪。agent 自己有改名办法的，用它自己的（在它的 CLI 里也看得到同一个名字，合“看上去就是 agent 自己做的”）；没有的，AgentSwitch 自己记，只在 AgentSwitch 里显示。
  4. Recently Opened 是什么。这一稿是“在 AgentSwitch 里最近打开过的”（含手机上开的）；也可以是“最近写过的”（别处在写的也算）。
