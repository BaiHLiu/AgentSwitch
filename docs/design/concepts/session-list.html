Terminals 列表 · 主次与找会话

配 docs/terminal-v0.md §1。左边是现在的列表，右边三种改法：A 文件夹做成组头、组内先放在跑的终端和子文件夹、历史会话收进一行；B 开着的和历史分成两段，历史可以按时间看；C ⌘P 找会话的面板（打字筛选，演示里能输入）。文件夹、终端、会话都是编的。A 的组头在滚动时停在顶上，滚一下列表看。

外观

为什么分不清、难找（照现在的规则）

  1. 一个文件夹里的顺序是终端、最新 3 条会话、N More，子文件夹排在最后，只比父级多缩进 14 点：子文件夹的标题行像是会话列表的下一条，父文件夹在哪里结束看不出来。
  2. 文件夹行 26 点、终端和会话行 28 点，文件夹只是字粗一点：没有底色、没有分界，组和组挨在一起。
  3. 在跑的终端和几十条历史会话在同一层，后者占了大部分行。
  4. 每个文件夹只露 3 条会话，其余在 More 后面，展开了也不记住；要找就得先记得在哪个文件夹。标题是第一句话，列表宽 300 点时只剩十来个字。没有按时间找的办法。

三种改法

  • A · 组头：文件夹行有底色和上下分界，滚动时停在顶上（子文件夹的停在它下面）；名字后面淡色写它在哪（~/Projects）。组内：在跑的终端 → 子文件夹 → History · 7（一行小标签，点它收起 / 展开），历史会话小一号、淡一档，先露 3 条，展开记住。组内一条竖线把内容连起来。改动小，结构不变。
  • B · 两段：上面 Open 只有开着的终端，按文件夹用一行小字分组；下面 Sessions，Folder / Time 可切：按时间时分 Today Yesterday This Week Earlier，每条第二行写文件夹、agent、时间。主次最清楚，但“这个项目里有什么”要看两段。
  • C · ⌘P：在哪一页都能按，输几个字（标题、文件夹名、说过的话）模糊匹配，最近的在前，每条带文件夹和时间；↩ 接着那个会话（开着的就切过去），⌘↩ 在旁边新开一块，esc 关掉。和 A 或 B 都能配。

建议：A + C——主次靠 A，找靠 C；B 改动最大，看过再定。另外几样小的，哪种都可以加：More 记住展开；会话能改名（列表里显示改过的名字）；会话能置顶（Pin，在组内排在最前）。
