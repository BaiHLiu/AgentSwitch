Files · 主窗口右边的文件栏

配 docs/files-v0.md（第二稿：第一稿的七件事已拍板）。文件栏是窗口自己的一栏，在所有终端之上：换终端、换页、分屏它都在；默认关着，靠边或浮起（⋯ › Float Over Page）。像素外观是 tree 式的目录树，经典外观是 Finder 式的文件夹（一次一层，拉宽到 460 点以上是分栏）；顶上是绝对路径，每一层可点。入口有三个：左边列表的右键 Show in Files、顶栏的文件夹图标（焦点那一块）、分屏时每块标题栏上的同一个图标。选中的文件 Add to Reply 或拖到某一块，落成回复框里的 [File #n]；可能含密码的文件先问一句。预览下面只有两个按钮，其余在右键菜单里；预览可以在 ⋯ 里关掉。手机多一个 Files 标签页；别的设备能读到哪些文件，在 Settings › Nodes 里给每个设备定。下面的窗口和手机都能点：树的 ▸、行（⌘ 点多选、⇧ 点连选、双击文件夹进入、右键）、路径的每一层、⌂、⋯、×、顶栏和标题栏的文件夹图标、左边列表的右键；焦点在文件列表里时 ↑ ↓ ← →、空格（Quick Look）、esc；文件栏的左边缘能拖。路径与文件都是编的。

5 · 拍板记录（files-v0 §10）
  1. 默认关。从入口打开以后记住开着。
  2. 快捷键照这一稿：⌘⇧F 开关、⌥↩ Add to Reply，其余照 Finder（⌘⇧H ⌘⇧G ⌘⇧. ⌥⌘C）。
  3. 经典拉宽是分栏：460 点以上，最后两栏（⑩）。
  4. 敏感文件看就行，给 agent 时提醒：~/.ssh/、.env、各 agent 的登录文件不锁，预览照常；加进回复框时问一次（⑦、手机 ⑧）。
  5. 手机开一个 Files 标签页：第五个，排在 Terminals 后面（手机 ⑦）。
  6. 远程读文件有节点自己的开关，并且每个设备一个授权范围（第 3 节）。
  7. 预览可以设置：⋯ › Show Preview，关了只在空格时看。

另两条：浮起随时能用（⑨，⋯ › Float Over Page）；预览下面只留 Add to Reply Open，Show in Finder 在右键菜单里（⑤）。这一稿顺手定的：默认靠边；浮起时点页面不收起；那一问在加进回复框时问一次，发送时不再问；新配对的设备默认 Home Folder。
