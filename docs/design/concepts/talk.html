Rooms · 几个 agent 在 AgentSwitch 里互相说话

配 docs/talk-v0.md。你建一个讨论，把几个终端拉进去；同一个讨论里的 agent 互相说话：话由服务转交，对方空闲时作为一句新的话打进它的终端；一轮由讨论里的话引起，这一轮的回答自动带回说话的那一位；要主动找人、点名说话，用终端启动时临时挂上的 room 工具（peers、send、read）。不写任何一家 agent 的用户配置，讨论的记录只在 AgentSwitch 的库里。全是演示数据。顶上一排是还没定的几件（talk-v0 §8），切换后整页跟着变。

谁建讨论 送达 回答 停下 放在
1 · ROOMS — 主窗口：一个讨论的两种看法
2 · IN THE TERMINAL — 终端里看到的
3 · NEW ROOM — 建讨论，和停下来等你的卡
4 · PHONE — 手机上同一个讨论
